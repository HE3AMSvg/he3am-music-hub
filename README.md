# 🎧 HE3AM Music Hub

یک پروژه سبک و شخصی برای ساخت تجربه‌ای شبیه هاب موسیقی در مرورگر؛ با تمرکز بر رابط کاربری ساده، فهرست پخش و پخش آهنگ‌ها.

## هدف پروژه

HE3AM Music Hub برای جمع‌آوری تجربه‌های رابط کاربری موسیقی در یک صفحه وب ساخته شده است. این مخزن نسخه ساده‌تر و اولیه‌تر هاب موسیقی HE3AM است و نباید آن را با سرویس استریم تجاری یا سرویس دارای کاتالوگ تضمین‌شده اشتباه گرفت.

## قابلیت‌ها

- رابط وب برای نمایش و کنترل پخش موسیقی
- امکان میزبانی استاتیک با GitHub Pages
- ساختار سبک و قابل اجرا در مرورگر
- قابلیت توسعه فایل‌های رابط و منطق برنامه به‌صورت جداگانه

## اجرای محلی

فایل `index.html` را در مرورگر باز کنید. برای تست از طریق یک وب‌سرور محلی نیز می‌توانید از دستور زیر استفاده کنید:

```bash
python -m http.server 8000
```

سپس آدرس `http://localhost:8000` را باز کنید.

## انتشار با GitHub Pages

فایل‌های پروژه را در شاخه اصلی مخزن قرار دهید و در مسیر **Settings → Pages**، انتشار از شاخه `main` و پوشه ریشه (`/ (root)`) را فعال کنید.

## ساختار اصلی

- `index.html` — ساختار صفحه و کنترل‌های پخش
- `style.css` — ظاهر و چیدمان رابط
- `app.js` — رفتارهای سمت مرورگر

## توسعه‌های آینده

اتصال پایدار به سرویس جست‌وجوی موسیقی، مدیریت بهتر کتابخانه و فهرست‌های پخش، و بهبود تجربه موبایل می‌توانند مسیرهای توسعه بعدی باشند.

> این پروژه یک نمونه شخصی/آزمایشی است. دسترسی به آهنگ‌ها و امکان پخش به منبع صوتی و محدودیت‌های همان منبع وابسته است.
